\# DVLD - Driver \& Vehicle Licensing Department System



An advanced management system designed to handle driver and vehicle licensing processes, built with a focus on \*\*Scalability\*\*, \*\*Maintainability\*\*, and \*\*Software Engineering best practices\*\*.



\## 🏗 System Architecture

The project follows the \*\*3-Layer Architecture (N-Tier)\*\* to ensure separation of concerns:



1\.  \*\*Presentation Layer (WinForms):\*\* The UI handles user interactions and input validation, ensuring a smooth user experience.

2\.  \*\*Business Logic Layer (BLL):\*\* Contains the core business rules and serves as a bridge between the UI and Data layers.

3\.  \*\*Data Access Layer (DAL):\*\* Responsible for all database communications (SQL Server), ensuring data integrity and efficient querying.



\## 🛠 Tech Stack

\* \*\*Language:\*\* C#

\* \*\*Framework:\*\* .NET Framework

\* \*\*Database:\*\* Microsoft SQL Server

\* \*\*UI:\*\* Windows Forms (WinForms)

\* \*\*Version Control:\*\* Git \& GitHub



\## 🚀 Key Features

\* \*\*User Management:\*\* Full CRUD operations for system users with different permission levels.

\* \*\*Person Management:\*\* A unified system to manage personal information across the application.

\* \*\*Application Tracking:\*\* Handling different types of license applications (New, Renew, Replace).

\* \*\*Tests \& Appointments:\*\* Managing vision, written, and practical driving tests.

\* \*\*License Issuance:\*\* Logic for generating and managing driver licenses.



\## 💡 Engineering Concepts Applied

\* \*\*Separation of Concerns:\*\* Each layer has a specific responsibility.

\* \*\*Encapsulation:\*\* Using class properties and methods to protect data.

\* \*\*Stored Procedures/SQL Logic:\*\* Efficient database management and security.

\* \*\*Error Handling:\*\* Robust try-catch blocks and logging for a crash-free experience.



\## 📁 Project Structure

\* `DVLD/`: The UI components and forms.

\* `DVLD\_BusinessLayer/`: Logic and business rules classes.

\* `DVLD\_DB\_Layer/`: Database access methods and connection handling.
